2026-10-27，ESP32-C3 revision v0.4，macOS，NimBLE 2.3.9。
控制输入分别为原生 USB Serial/JTAG 和加密 BLE；HID 输出均为 BLE 到同一台 Mac。
每项连续测量 30 次，保持连接，排除首次串口打开和 BLE 发现/连接耗时。

## 实现

- 认证成功和 arm 时请求 15ms / latency 0；`ping` 返回实际协商参数。
- 支持免 ATT 响应的特征使用 WRITE without response，仍逐条等待随机 ID 的协议 ACK。
  旧固件沿用 WRITE with response。超时、断线或未知投递不自动重发。
- 移动/滚轮移除固定 35ms 等待；BLE 键盘/点击最小脉冲 8ms。
- BLE 输入报告按实际连接间隔限速，按下和释放各占一次预算。单独 8ms 脉冲的试验版
  持续压测时耗尽 TX 缓冲，已替换。连续 USB 键盘命令约 30ms 来自两个输入报告的节流。
- USB 每轮最多处理 512 字节；主机按实际可读字节读取，避免固定长度读取的等待。
  C3 DTR/RTS 在打开串口前设定，减少误触复位。
- S3 USB HID 保留 35ms 按下、20ms 间隔；S3 仅编译，未做实板延迟验证。

## 使用与验证

使用本仓库更新后的主机代码及 `.venv/bin/esp-use` / MCP server，保持 transport
连接存活。旧插件缓存里的 0.2.0 wheel 不会自动获得本仓库主机端的优化；
本次没有修改已安装插件或全局配置。

本轮完整 BLE OTA：681,408 字节，59.497 秒，11,453 bytes/s。重启后在 app0
运行 0.3.1，ELF 身份匹配并确认。0.3.0 的 A/B 自动回滚已通过实板测试。
